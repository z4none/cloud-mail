# 邮件会话卡片展示设计

日期：2026-10-03

## 目标

将会话详情从连续的邮件正文改为现代卡片布局，让收到的邮件与我方回复在视觉上清晰区分，同时保留完整正文、附件和现有操作。

## 视觉规则

- 详情滚动区域采用低对比浅灰背景。
- 每封邮件为独立卡片：12px 圆角、细边框、轻阴影，卡片之间保留 14px 间距。
- 收到邮件使用白色/中性卡片。
- 已发送邮件使用主题色低饱和背景和左侧主题色强调条。
- 会话最新邮件额外加深边框和阴影。
- 卡片头部包含发件人首字母头像、名称、地址、收件人和时间；窄屏自动换行。
- 卡片头部提供对应单封邮件的回复、转发和删除操作；删除仍只影响该邮件。
- 正文、投递状态和附件在卡片中分区，附件维持现有预览和下载行为；邮件正文默认背景与当前主题一致。

## 边界

仅调整 `mail-vue/src/views/content/index.vue` 的会话展示样式与语义结构。不改变 API、数据模型、邮件内容、回复/转发、已读、删除、星标或对象访问逻辑。

## 验证

- Vue release 构建通过。
- 桌面和移动断点下卡片可读且无水平溢出。
- 收件、已发送、附件、HTML 正文和纯文本正文均保留。
