# 居中登录框与克制背景动效设计

日期：2026-10-03

## 目标

将登录页改为居中的独立登录框，营造可信、稳重的团队邮箱入口；背景保持简洁，以低饱和 CSS 动效提供轻微层次而不分散注意力。

## 布局

- 登录框在水平和垂直方向居中，宽度受限于约 420px。
- 框体包含品牌区、登录表单和辅助操作，使用克制圆角、细边框与柔和阴影。
- 窄屏保留足够页面边距，登录框随视口缩放。

## 背景和动画

- 由两组大型、低饱和蓝灰伪元素及细网格纹理组成。
- 仅缓慢变更位置和透明度，动画周期 18–25 秒。
- 浅色与深色主题使用对应的色彩和对比度。
- `prefers-reduced-motion: reduce` 时停用动画。

## 边界

仅变更登录页布局和样式，不改变认证、验证码、注册、找回密码或语言切换逻辑。

## 验证

- 前端 release 构建通过。
- 桌面和窄屏下登录框保持可见且无横向溢出。
- 浅色、深色及减少动态偏好均有可读的静态状态。
