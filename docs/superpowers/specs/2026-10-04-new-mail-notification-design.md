# 新邮件通知设计

日期：2026-10-04

## 目标

当收件箱后台轮询发现新邮件时，为用户提供及时、可控且不重复的新邮件提醒，并能从通知直接打开对应会话。

## 页面内通知

- 使用现有 Element Plus `ElNotification`。
- 通知显示发件人、主题和会话消息数量。
- 点击通知打开对应邮件会话。
- 同一次轮询发现多封邮件时合并为一条通知，避免连续弹窗。
- 用户当前正在查看该会话时不弹通知。
- 文案加入中英文 i18n，不写死单一语言。

## 浏览器通知

- 仅在用户明确授权后启用，不自动反复请求权限。
- 页面处于后台或不可见时，使用浏览器 `Notification` 提醒。
- 点击通知聚焦窗口并打开对应会话。
- 权限被拒绝或浏览器不支持时，继续使用页面内通知，不影响轮询。

## 去重与状态

- 以 `emailId` 记录已通知邮件，避免同一轮询结果重复提醒。
- 首次加载历史列表不触发通知。
- 只对后台轮询期间发现的新增邮件触发通知。
- 同一会话在一次轮询中只产生一条通知，通知内容使用最新邮件并显示新增邮件数量。

## 实现边界

- 复用现有 `views/email/index.vue` 的 `/email/latest` 轮询链路。
- 新增独立通知工具，负责权限、页面可见性、去重和通知点击回调。
- 不改变邮件 API、线程聚合逻辑或邮件持久化数据。
- 保持浅色/深色主题下页面内通知的可读性。

## 验证

- 新邮件触发页面内通知。
- 同一轮多封邮件合并通知。
- 当前打开会话不重复提醒。
- 浏览器通知权限允许、拒绝和不支持时均能正常降级。
- 点击页面内或浏览器通知可打开对应会话。
- 首次加载和刷新不会为历史邮件误发通知。
- Worker 测试与前端 release 构建通过。
